# MacBook Duo

一个免费的开源 macOS 原型：让桌面随 MacBook 屏幕开合产生空间视差、渐进失焦和边缘散射。

技术栈：Swift 6、AppKit、Metal、ScreenCaptureKit、IOKit HID。

界面支持简体中文、繁體中文、English 和 Español。语言选择在应用窗口中即时生效，并保存在本机，下次启动会沿用；首次启动会根据 macOS 首选语言自动选择。

## 运行

打开 `dist/MacBook Duo.app`。拖动角度滑块或点击“播放”即可预览，无需屏幕录制权限。

- 勾选“跟随真实屏幕”：用内置铰链传感器控制预览。
- “将当前角度设为展开”：校准你习惯的正常开屏角度。
- 透视、柔焦、阴影滑块：实时调整效果。
- “启用真实桌面”：首次使用会申请屏幕录制权限；在系统设置中允许后重新打开应用并再次启用。
- 正常展开时效果覆盖层隐藏。菜单栏“停止桌面效果”始终可用。应用获得键盘事件时 Esc 也能停止；其他应用前台时，全局 Esc 是否可用取决于 macOS 的输入权限，优先使用菜单栏。
- 睡眠或显示器布局变化会停止真实桌面模式，醒来后手动重新启用。

## 构建

需要 Swift 6.2 以上开发工具，运行目标 macOS 14 以上。

```sh
./scripts/build-app.sh
.build/release/MacBookDuo --probe
```

生成的 app 为本机 ad-hoc 签名，尚未做 Developer ID 签名或公证。更新构建后系统可能要求重新授权。

## 实现与边界

- 传感器通过 IOKit HID Feature Report 读取，30 Hz 采样；在本机 M3 Pro MacBook Pro 已读到有效角度。
- Metal 从固定观察点穿过绕底部旋转的屏幕，采样后方不动的桌面平面；根据两层间距增加高斯柔焦和阴影，铰链处保持清晰。空间关系参考 iPhone Duo 演示的射线投影思路：https://github.com/jadon7/iphone-duo 。着色器为独立实现。
- 真实桌面捕获仅针对内置显示屏，排除效果窗口，30 fps，不录制音频，不写入或上传图像。
- 覆盖层允许鼠标穿透。变形期间视觉位置与底层点击位置不同，应在展开状态操作桌面。
- 预览、滑块和传感器已实机验证；真实桌面模式需用户授权后进一步验证。锁屏、受保护视频、不同显示缩放和长时间性能尚未验证。
- 当前是视觉效果原型；不是系统窗口几何变换，也不改变合盖睡眠行为。

HID 设备标识与报告格式参考 Sam Gold 的公开项目：
https://github.com/samhenrigold/LidAngleSensor 。本项目未引入其源码或资源。
